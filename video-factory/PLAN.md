# Video Factory — План автоматичного створення відео для YouTube

## Мета
Автоматична система, яка:
1. Приймає ідею/тему від користувача
2. Генерує сценарій (текст)
3. Шукає безкоштовні відео/фото з вільними правами
4. Робить озвучку (TTS)
5. Монтує все в 1080p HD відео для YouTube

## Архітектура

### Компоненти:
- **Frontend**: HTML форма для вводу ідеї/теми
- **Backend**: Python (Flask/FastAPI)
- **Pipeline**: Сценарій → Медіа → TTS → Монтаж → Відео

### Технології (все безкоштовно):

| Компонент | Технологія | Опис |
|-----------|-----------|------|
| Backend | Flask | Python веб-сервер |
| Сценарій | AI (GPT) або шаблони | Генерація тексту |
| Медіа (фото/відео) | Pexels API | 200 requests/hour безкоштовно |
| Медіа (fallback) | Pixabay API | Безкоштовно |
| TTS | Edge TTS | Безкоштовно, якісний голос |
| Монтаж | MoviePy + FFmpeg | Python бібліотека |
| Вихід | 1080p MP4 | 1920x1080, H.264, AAC |

## Безкоштовні джерела медіа (CC0 / Creative Commons)

1. **Pexels** (pexels.com)
   - API: https://api.pexels.com/v1/
   - 200 requests/hour безкоштовно
   - Ліцензія: Pexels License (можна використовувати, модифікувати, без атрибуції)
   - Можна монетизувати

2. **Pixabay** (pixabay.com)
   - API: https://pixabay.com/api/
   - Pixabay License (можна використовувати без обмежень)
   - Можна монетизувати

3. **Coverr** (coverr.co)
   - Безкоштовні відео
   - Можна монетизувати

4. **Mixkit** (mixkit.co)
   - Безкоштовні відео та музика
   - Можна монетизувати

## Формат відео
- **Роздільність**: 1920x1080 (Full HD)
- **Аспект**: 16:9
- **Кодек**: H.264 (video), AAC (audio)
- **Контейнер**: MP4
- **Тривалість**: 8-15 хвилин (на основі сценарію)
- **FPS**: 24 або 30

## Pipeline (кроки):

### 1. Ввід теми
Користувач вводить:
- Тема/ідея відео
- Тональність (навчальний, розважальний, драматичний)
- Тривалість (коротке 5-8 хв, середнє 10-15 хв, довге 20-30 хв)
- Цільова аудиторія

### 2. Генерація сценарію
- AI генерує сценарій з розбивкою на сцени
- Кожна сцена: текст для озвучки + опис візуалу для пошуку медіа
- Формат JSON:
```json
{
  "title": "...",
  "scenes": [
    {
      "scene_number": 1,
      "narration": "Текст для озвучки",
      "visual_description": "Ключові слова для пошуку відео/фото",
      "duration": 10
    }
  ]
}
```

### 3. Пошук медіа
- Для кожної сцени — пошук за `visual_description`
- Пріоритет: відео > фото
- Fallback: якщо немає відео — використовуємо фото + Ken Burns effect
- Завантаження файлів локально

### 4. Озвучка (TTS)
- Edge TTS — безкоштовно, багато голосів
- Російська, українська, англійська підтримка
- Розбивка на сегменти (один сегмент = одна сцена)
- Збереження аудіо для кожної сцени

### 5. Монтаж (MoviePy)
- Для кожної сцени:
  - Відео/фото + аудіо (TTS)
  - Субтитри (опціонально)
  - Переходи між сценами (crossfade)
- Склеювання всіх сцен
- Фонова музика (Mixkit, безкоштовна)
- Збереження в 1080p MP4

### 6. Вивід
- Файл: `video_YYYY-MM-DD_HH-MM-SS.mp4`
- Можливість скачати
- Збереження в історію

- Розмір: залежить від тривалості
- Місце на диску: ~500MB тимчасових файлів
