## Правила для мене
1. **Працюю тільки в одному контексті за раз** — якщо ти не вказав який, питаю
2. **Не змішую контексти** — дані з T1 не використовую в T2 без твого дозволу
3. **При переключенні** — короткий summary що було зроблено, що планується
4. **Нові задачі** — якщо задача з нової області, створюю новий контекст з ID

## Як ти можеш використовувати
- **"Продовжуй T1"** — продовжую роботу зі скрінером
- **"Нова задача: [опис]"** — створюю новий контекст
- **"Переключись на T2"** — переключаюсь на джерела даних
- **"Покажи всі задачі"** — показую цей файл
